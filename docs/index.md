# Kanvas Documentation

Kanvas turns Blender's Node Editor into a freeform reference board. Place images, notes, checklists, frames, and arrows on an infinite canvas, mark up references with masks and colors, and keep everything in your `.blend` file.

This documentation is written for people who use Kanvas. It explains what each tool does and how to get the most out of it.

## Conventions used in these pages

- **Kanvas Tree** is the editor type that shows a board. Each tree holds one independent board.
- The **sidebar** is Blender's `N` panel. Kanvas controls are under the **K-Tools** tab.
- Keys are written like `Shift + D`. `Numpad .` is the period key on the numeric keypad.
- Shortcuts only work while the pointer is over the canvas of a Kanvas Tree. They never affect other Blender editors.
- Every shortcut can be changed under **Preferences > Add-ons > K-Tools: Kanvas > Controls**.

> Kanvas is under active development. This documentation describes the current behavior of the add-on.
