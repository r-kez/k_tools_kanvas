# Arranging items

Kanvas has several tools for tidying a board. All of them act on the selected, unlocked items.

## Align

Select two or more items and use the **Align** panel, or **Align** in the right-click menu.

You can align to the left, center, or right, and to the top, middle, or bottom. Items line up with the chosen edge or center of the selection.

## Distribute with even gaps

Select **at least three** images or cards and choose **Distribute Horizontally** or **Distribute Vertically**.

- When there is room, the outer items stay where they are and the gaps between edges are made equal.
- When items overlap or there is not enough room, the group expands around the center of the selection, with 20 units between items.
- **Align Centers** is on by default and also lines the other axis up into a row or column. Turn it off in the operation panel (press `F9` after running the command) to keep the positions on that axis.

## Pack

**Pack** (`P`) places the selected images in neat rows with even gaps. It is the fastest way to turn a pile of freshly imported images into a readable layout.

Pack changes the layout only. It does not change how images are stored.

## Match image sizes

| Command | Result |
| --- | --- |
| **Average Image Size** | Gives the selected images the same displayed longest edge |
| **Average + Pack** | Matches sizes, then packs them |

Both are in the **Selection** panel when images are selected.

## Reset transforms

`Alt + G`, `Alt + S`, and `Alt + R` reset location, scale and shear, and rotation. See [Selecting and transforming](transforms.md#reset).

## Finding things

| Action | How |
| --- | --- |
| Frame the selection | `Numpad .` |
| Find content that is off-screen | Click the **Recenter** button |
| Find an item by name | Type in the **Search** field of the item list |
