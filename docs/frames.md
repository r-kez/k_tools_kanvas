# Frames

A **frame** groups items. Moving the frame moves everything inside it, and the frame can resize itself to fit its content. Frames can contain other frames.

## Creating a frame

- Select items and press `Shift + F`. A frame is created around the selection.
- Use **Add > Frame**, or choose **Create Frame** in the right-click menu.

With nothing selected, **Add > Frame** creates an empty frame at the pointer.

## Working with frames

| To | Do this |
| --- | --- |
| Move a frame and its content | Drag the frame **header** |
| Select with a box inside a frame | Drag on the frame body |
| Rename a frame | Select it and press `F2`, or edit its name in the **Selection** panel |
| Release items from their frame | Select them and press `Alt + U`, or use **Release from Frame** in the right-click menu |
| Release an item while moving it | Hold `F` while you move the item |
| Attach items to a frame | Use **Attach Selection to Frame** in the right-click menu |

Items that you move or import into a frame can attach to it automatically. The frame title is drawn in the header and adjusts to the space available at the current zoom.

## Automatic resizing

A frame that has content resizes itself to fit it, and stays correct as you add, move, or remove items.

An **empty** frame shows a corner handle and the **Width** and **Height** fields, so you can size it yourself. **Fit Frame to Content** in the **Selection** panel or the right-click menu resizes a frame around its content on demand.

## Frame settings

Select a frame and open the **Selection** panel:

| Setting | Effect |
| --- | --- |
| **Color** | The frame color |
| **Opacity** | Transparency of the frame background |
| **Header Font Size** | Size of the title text |
| **Width / Height** | Manual size, for empty frames |
| **Fit Frame to Content** | Resize to match the items inside |

The panel also shows which frame contains the selected frame, and how many items a frame holds.

## Locking a frame

Locking a frame in the item list **locks everything inside it**, including nested frames. Unlocking it releases them all. Locked items cannot be selected, moved, transformed, duplicated, or deleted, and a padlock appears next to the frame's name so you can tell at a glance.
